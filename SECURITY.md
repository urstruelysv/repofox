# Security Policy

Thanks for helping keep RepoFox safe.

## Supported Scope

Please report security issues that affect:

- the VS Code extension in `apps/vscode`
- the shared workflow engine in `packages/core`
- secret handling and persisted state
- release or packaging workflow issues that could impact users

## How to Report

Please do not open public GitHub issues for suspected security vulnerabilities.

Instead, email `security@repofox.dev` with:

- a description of the issue
- reproduction steps
- impact assessment
- any proof-of-concept material
- your preferred contact details

We will acknowledge receipt as soon as possible and work with you on validation and remediation.

## What to Include

Helpful reports usually include:

- affected files or features
- required environment or permissions
- whether the issue is local-only or remote-impacting
- whether secrets, repositories, or GitHub tokens are exposed

## Disclosure

Please give us reasonable time to investigate and ship a fix before public disclosure.
